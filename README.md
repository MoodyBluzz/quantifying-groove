# Quantifying Groove: Herbie Groove Profile: A Music Information Retrieval Analysis of Expressive Piano Performance
This project investigates Herbie Hancock’s expressive performance style using Music Information Retrieval (MIR) techniques and computational audio analysis.

The analysis combines microtiming deviations, dynamic intensity, spectral brightness and harmonic complexity to construct a multidimensional Groove Profile across recordings from the 1960s, 1970s and 1980s.

The project demonstrates a complete MIR workflow, including onset detection, beat tracking, feature extraction, statistical analysis and correlation modeling, providing a computational representation of expressive keyboard performance.
